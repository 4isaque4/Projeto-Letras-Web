# Insumos do Projeto

Este diretorio concentra materiais brutos usados como referencia durante o desenvolvimento, separados por funcionalidade para evitar arquivos soltos na raiz.

## Estrutura

- `design-etapa1/`: pacotes, capturas e prototipos de apoio visual da Etapa 1.
- `regras-negocio/`: fonte original e extracoes usadas para consolidar regras.
- `reunioes/`: gravacoes, transcricoes e anexos de reunioes.
- `planejamento/`: planilhas e apoio de acompanhamento.

## Regra de organizacao

Sempre mover novos anexos para um desses grupos (ou criar subpastas por data/tema), mantendo a raiz do repositorio limpa.
